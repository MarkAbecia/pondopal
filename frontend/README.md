# PondoPal frontend

This is the Expo app (SDK 58), written in TypeScript in strict mode, with Expo Router. Routes live in `src/app/`, which is the SDK 58 default. Everything else that isn't a route lives elsewhere in `src/`.

```bash
cp .env.example .env    # fill from `supabase status`
npm install
npm start
```

| Script | Does |
|---|---|
| `npm run typecheck` | `tsc --noEmit` |
| `npm run lint` | ESLint (`eslint-config-expo`) |
| `npm test` | Jest (`jest-expo`) |

- Add dependencies with `npx expo install <pkg>` so the versions match the SDK.
- `src/types/database.ts` is generated by `database/scripts/gen-types.sh`. Don't edit it.
