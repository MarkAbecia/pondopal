# PondoPal frontend

This is the Expo app (SDK 58), written in TypeScript in strict mode. It uses Expo Router, NativeWind, TanStack Query, Zustand, react-hook-form with zod, and i18next. Routes live in `src/app/`, which is the SDK 58 default.

```bash
cp .env.example .env    # fill from `supabase status` (anon key) and the API URL
npm install
npm start
```

| Script | Does |
|---|---|
| `npm run typecheck` | `tsc --noEmit` |
| `npm run lint` | ESLint (`eslint-config-expo`) |
| `npm test` | Jest (`jest-expo`) and React Native Testing Library |

## How it fits together
- **Money:** `src/lib/money.ts` (`toCentavos`, `fromCentavos`, `formatPHP`) is the only place that converts or displays amounts. It parses strings digit by digit and never goes through floats.
- **Dates:** `src/lib/dates.ts` uses Asia/Manila calendar days and months.
- **Auth:**
  - The Supabase session is stored in SecureStore, split into chunks (`src/lib/secure-storage.ts`).
  - The root layout shows the sign-in screens or the app depending on the session (`Stack.Protected`).
  - Google and Apple sign-in use Supabase OAuth with PKCE, in an auth-session browser.
  - Phone sign-in uses an OTP. Locally, `+639170000000` accepts code `123456` (see `database/supabase/config.toml`).
- **Offline:**
  - The TanStack Query cache is saved to AsyncStorage and cleared on sign-out.
  - Saving or deleting a transaction updates the list optimistically right away.
  - If you're offline, the change pauses and is kept across app restarts. It replays once the network returns, because the mutation logic is registered as defaults (`registerTransactionMutations`).
  - New transactions get their id on the device, so a retried save can never create a duplicate.
- **Realtime:** the tab layout subscribes to `transactions`, `challenge_entries` and `goal_contributions` for the active space, so other members' changes refresh lists, grids and goals live.
- **Ipon:** challenge amounts come from the backend (`/v1/challenges/...`); `src/features/ipon/grid.ts` only labels cells. Ticking a cell shows right away and rolls back if the request fails. Ticking needs a connection.
- **Push:** after sign-in the app asks for notification permission and saves the Expo push token to your profile. This needs an EAS project id (`extra.eas.projectId`, set by `eas init`); without one, push is skipped and reminders only appear in the in-app inbox. Signing out clears the token.
- **Spaces:**
  - The header switcher sets the active space, which is persisted in Zustand.
  - The home screen rolls up this month's totals across every space you belong to.
- **Database types:** `src/types/database.ts` is generated by `database/scripts/gen-types.sh`. Don't edit it.
- **Adding dependencies:** use `npx expo install <pkg>` so versions match the SDK.
